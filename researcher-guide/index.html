개별 메일의 본인 계정으로 로그인해 주세요. KQ는 핵심질문(Key Question)을 뜻합니다. 같은 KQ를 담당하는 두 교수님께 각각 계정을 안내합니다. 각자 독립적으로 검수·평가해 주세요.

01 / Participation

원문을 먼저 확인하고, 답변을 평가합니다.

화면의 담당 KQ와 배정 항목을 확인해 주세요. 조작 방법은 교육 영상의 A·B 파트에서 볼 수 있습니다.

실제 리뷰 사이트에서도 교육 영상을 열 수 있습니다.

리뷰 사이트 로그인→화면 상단→평가자 교육 가이드→A. 원문 검수 / B. 응답 평가

검수 중에도 상단의 「평가자 교육 가이드」 버튼을 눌러 주세요. 안내 화면에서 A 또는 B를 선택해 주세요.

아래 영상은 새 창에서 열립니다. 로그인 화면이 나오면 본인 계정으로 접속해 주세요. 이후 상단 버튼에서 해당 안내를 열어 주세요.

1. 원문 검수 안내 ↓2. 응답 평가 안내 ↓
1. 원문검수 · 교육 영상 A

옮겨 온 값이 원문과 같은가?

원문 PDF와 항목별 값을 나란히 대조합니다.

▶교육 영상 A · 10개 장면원문 검수 안내항목 선택 · 값 대조 · 판정 · 서버 저장영상 안내 열기 ↗

안내 화면에서 재생 버튼을 눌러 주세요. 필요한 장면을 선택하거나 재생 속도를 조절할 수 있습니다.

원문 검수 단계표
단계화면에서 할 일
01항목 선택「1. 원문검수」를 열어 주세요.
검수 항목과 세부 항목을 선택해 주세요.
02원문 대조원문 값과 정규화 값의 뜻을 대조해 주세요.
수치·단위·신뢰구간·대상군을 확인해 주세요.
근거수준·MCID/OIS·권고문도 확인해 주세요.
03판정 선택일치할 때도 「원문과 일치」를 클릭해 주세요.
다르면 「수정 필요」를 선택해 주세요.
04수정·유보 기록수정값과 원문의 쪽·표·행을 적어 주세요.
원문이 모호하면 「판단 유보」와 이유를 남겨 주세요.
05다음 항목「다음 항목」으로 이동해 주세요.
같은 순서로 담당 항목을 확인해 주세요.
06서버 저장「판정 저장」을 눌러 주세요.
서버 저장 안내와 완료 수를 확인해 주세요.
작업을 멈추기 전에도 저장해 주세요.
기본 선택과 임시 보관만으로 검수는 완료되지 않습니다.

판정을 직접 선택하고 「판정 저장」을 눌러 주세요. 빈칸은 0을 뜻하지 않습니다.

2. Chatbot 응답평가 · 교육 영상 B

답변이 근거를 정확히 전달하는가?

질문과 기대정답 카드를 보며 익명 응답 A·B·C를 평가합니다.

▶교육 영상 B · 8개 장면응답 평가 안내체크리스트 · 쌍대 비교 · 종합 판단 · 저장영상 안내 열기 ↗

안내 화면에서 B 파트를 선택해 재생해 주세요. 영상의 예시는 교육용이며 실제 평가 응답과 다릅니다.

Chatbot 응답평가 단계표
단계화면에서 할 일
01문항 확인「2. Chatbot 응답평가」를 열어 주세요.
질문·기대정답 카드와 응답 A·B·C를 읽어 주세요.
02체크리스트자동 판정을 확인하고 틀린 칸을 고쳐 주세요.
검토 후 「모두 확인」을 눌러 주세요.
03쌍대 비교임상 적절성과 전달 품질을 판단해 주세요.
각 기준에서 A–B, A–C, B–C를 비교해 주세요.
더 나은 응답이나 동률을 선택해 주세요.
04종합·오류 확인종합 선호와 한 줄 이유를 적어 주세요.
각 응답의 오류 문장에 태그를 붙여 주세요.
오류가 없으면 「오류 없음」을 표시해 주세요.
05저장·다음 문항「저장 후 다음 문항」을 눌러 주세요.
서버 저장 상태를 확인해 주세요.
06KQ 최종 판단배정 문항을 마치면 KQ 판정을 해 주세요.
공개 가능 여부와 필요한 개선 사항을 남겨 주세요.
자동 판정은 참고 자료입니다.

응답을 직접 읽고 판정을 확정해 주세요. 각 응답의 오류 확인도 완료해 주세요.

임상 적절성+전달 품질정확하고 오해 없이 전달하는 답변을 판단합니다.

응답의 시스템을 추측하지 말고 내용만 평가해 주세요. 담당 KQ 평가 후에는 공개 가능 여부도 판단해 주세요.

02 / Knowledge structure

같은 근거를 세 가지 방식으로 활용합니다.

연구팀은 KQ 원문과 결과보고서를 구조화합니다. 데이터의 의미·수치·출처를 연결해 챗봇이 조회할 수 있게 만듭니다.

ONTOLOGY

무엇이 같은 개념인가?

약제·결과지표·효과 수치·권고의 의미와 관계를 정의합니다.

같은 표현처럼 보여도 측정도구·단위·대상군이 다르면 구분합니다.

GRAPH DATABASE

어떤 근거와 연결되는가?

효과 수치와 근거수준을 출처에 연결합니다.

전체 대상군과 하위군을 구분하고, 해당 조건의 값을 조회합니다.

VECTOR DATABASE

어느 문단에 설명이 있는가?

질문과 의미가 가까운 문서 구절을 검색합니다.

표 밖의 설명과 문맥을 답변의 근거로 제공합니다.

검색 방식

RAG는 문서 검색을 이용한 답변 생성입니다. Graph 방식은 구조화 근거를 조회합니다. Hybrid 방식은 그래프 조회와 문서 검색을 함께 사용합니다.

03 / Research plan

세 연구가 서로 다른 질문을 다룹니다.

검수·평가 결과는 아래 연구에 활용할 계획입니다. 시스템의 우월성이나 비열등성을 확인한 결과 보고서가 아닙니다.

PAPER 01

지식그래프의 구축과 검증

원문의 근거를 빠짐없이 정확하게 구조화했는가?

추출 값의 일치, 정보의 누락, 관계의 무결성을 확인합니다. 표준 용어와의 연결도 검토합니다.

교수님 기여: 원문 검수와 수정 근거.

PAPER 02

검색 방식에 따른 답변 품질

같은 언어 모델에서 근거 제공 방식이 품질에 영향을 주는가?

문서 검색과 하이브리드 방식의 전문가 평가를 비교합니다. Graph 단독 방식은 자동 평가에도 포함합니다.

교수님 기여: 필수 기준 판정과 응답 간 비교.

PAPER 03

로컬 언어 모델의 대체 가능성

하이브리드 근거를 제공하면 로컬 모델도 유용한 답변을 만드는가?

상용 모델과 로컬 모델의 품질 차이를 추정합니다. 이번 자료는 탐색 분석에 사용합니다.

교수님 기여: 같은 평가 세션의 응답 판정.

일차 평가 지표는 ‘근거응답 합격률’입니다. 문항별 필수 기준을 충족하고 수치 오류·무근거 오류가 없는지를 봅니다. 자동 평가와 언어 모델의 심사는 전문가 판정과 비교합니다.

모델·슬롯의 대응은 공개하지 않습니다. 연구 2와 연구 3은 공통 자료 사용을 논문에 명시합니다. 로컬 모델의 비열등성 확증은 독립 자료를 갖춘 후속 연구에서 검토합니다.

04 / Study boundaries

확정한 절차와 남은 확인을 구분합니다.

현재 안내에 적용

진행 기준

  • 원문 검수 후 응답 평가연구팀이 검수 결과로 기대정답 카드를 갱신합니다.
  • 개별 계정과 독립적인 판단화면에 배정된 담당 KQ와 항목을 평가합니다.
  • 익명 응답과 내용 중심의 평가체크리스트·쌍대 비교·오류 확인을 사용합니다.
  • 원문과 판정의 연결 기록수정할 값과 원문 위치를 함께 남깁니다.
연구팀 확인·후속 작업

확정 전인 부분

  • 필수 기준표의 최종 고정파일럿 평가 의견을 반영해 분석 전에 고정합니다.
  • KQ별 검수 완료와 카드 갱신해당 단계의 준비 여부는 운영팀이 별도로 안내합니다.
  • 분석 계획·윤리 정보의 문서화상세 분석 방법과 IRB 승인 정보를 연구 문서에 정리합니다.
  • 비열등성 확증 연구의 설계허용 차이·표본수의 기존 제안은 승인된 확증 설계가 아닙니다.
05 / Practical notes

검수 중에는 이렇게 처리해 주세요.

원문과 화면의 값이 다릅니다.

「수정 필요」를 선택해 주세요. 바른 값과 PDF의 쪽·표·행을 적어 주세요. 원문끼리 충돌하면 「판단 유보」와 이유를 남겨 주세요.

빈칸이나 ‘정보 없음’은 어떻게 판단하나요?

빈칸은 0을 뜻하지 않습니다. 원문에 값이 있으면 수정 내용을 적어 주세요. 원문에도 없으면 「원문 미기재」를 메모해 주세요.

근거가 없는 질문에서 답을 보류한 것은 정상적인 안전 행동입니다. 근거가 있는데 답하지 못했다면 해당 기준을 미충족으로 판단해 주세요.

평가를 나눠서 진행해도 되나요?

작업을 멈추기 전에 저장 상태를 확인해 주세요. 원문 검수는 「판정 저장」이 필요합니다. 응답 평가도 문항을 저장한 뒤 종료해 주세요.

항목이나 문항 수는 어디서 확인하나요?

로그인 후 현재 화면의 배정 목록을 확인해 주세요. KQ와 평가 단계에 따라 범위가 다릅니다. 접속·저장 문제는 안내 메일로 회신해 주세요.
