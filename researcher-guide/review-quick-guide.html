교수님 검수·평가 안내

담당 KQ의 원문 검수를 먼저 진행해 주세요.

KQ는 핵심질문(Key Question)을 뜻합니다.
연구팀이 검수 내용을 반영한 뒤 응답 평가를 안내합니다.

검수·평가 사이트교육 영상 A교육 영상 B연구 개요

검수·평가: https://review.asthma-guideline.kr

교육 영상: https://review.asthma-guideline.kr/viz/expert_eval/evaluator_training_guide_v0.5.html#review

연구 개요: https://drugnsafety.github.io/pacen-severe-asthma-guideline/researcher-guide/

  • 개별 메일의 본인 계정으로 로그인해 주세요.
  • 함께 담당하시는 교수님과 각각 독립적으로 평가해 주세요.
  • 화면에 배정된 담당 KQ와 문항을 확인해 주세요.
  • 리뷰 사이트 상단의 「평가자 교육 가이드」를 눌러 주세요.
  • 안내 화면에서 A(원문 검수) 또는 B(응답 평가)를 선택해 주세요.
  • 재생 버튼을 눌러 주세요. 필요한 장면을 선택할 수도 있습니다.

1. 원문 검수

  1. 「1. 원문검수」에서 항목을 선택해 주세요.
  2. 화면의 값과 원문 PDF를 대조해 주세요.
  3. 판정을 직접 클릭해 주세요.
  4. 수정이 필요하면 바른 값과 원문 위치를 적어 주세요.
  5. 「판정 저장」을 눌러 서버 저장을 확인해 주세요.

연구 대상·권고문·효과 수치·근거수준을 확인합니다.
MCID/OIS·하위군 등도 해당 항목에서 확인합니다.
MCID는 최소 임상적으로 중요한 차이, OIS는 최적 정보량입니다.

기본 선택만 유지하면 검수 완료로 기록되지 않습니다.

일치할 때도 「원문과 일치」를 직접 클릭해 주세요.

애매한 값은 「판단 유보」로 남겨 주세요.

작업을 멈추기 전에 「판정 저장」을 눌러 주세요.

2. Chatbot 응답평가

연구팀이 검수 결과로 기대정답 카드를 갱신합니다.
연구팀의 응답 평가 안내 후 다음 순서로 진행해 주세요.

  1. 질문과 기대정답 카드를 확인해 주세요.
  2. 익명 응답 A·B·C의 체크리스트를 확인해 주세요.
  3. 자동 판정이 틀리면 수정한 뒤 확정해 주세요.
  4. 응답을 두 개씩 비교해 더 나은 쪽이나 동률을 골라 주세요.
  5. 종합 선호와 응답별 오류 여부를 기록해 주세요.
  6. 문항을 저장한 뒤 저장 상태를 확인해 주세요.

비교 기준은 임상 적절성과 전달 품질입니다.
오류가 없으면 각 응답에 「오류 없음」을 표시해 주세요.
답변을 만든 시스템을 추측하지 말고 내용만 평가해 주세요.
담당 KQ 평가 후에는 공개 가능 여부도 판단해 주세요.

문의

접속·저장 문제나 판단이 어려운 항목은 안내 메일로 회신해 주세요.
문의할 때 KQ 번호와 화면의 항목명을 함께 적어 주세요.

연구·교육 목적의 평가입니다.
챗봇은 특정 환자에 대한 임상 판단을 대신하지 않습니다.
