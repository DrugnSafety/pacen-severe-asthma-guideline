# 성인 중증천식 진료 가이드라인 — 홈페이지 개편 프로토타입

> **⚠️ DRAFT · 내부 검토용** — 본 저장소의 콘텐츠는 학회 인증·최종 승인 **전** 개발 중 상태의 프로토타입입니다. 현행 공식 홈페이지는 [pacen.myadr.care](https://pacen.myadr.care) 입니다.

성인 중증 천식 환자의 생물학적제제 사용에 대한 근거기반 진료지침(개발: 대한천식알레르기학회 KAAACI 위임 · 보건복지부 PACEN 사업, 과제번호 RS-2025-02303166)의 **홈페이지 개편 프로토타입**입니다.

- 공식 과제명: **성인 중증 천식 생물학적 치료제 가이드라인** (진료지침 통합본 I-17 확정, 2026-08-25)
- 주관연구기관: 서울아산병원 · 연구기간 2025.4 ~ 2026.3

## 프로토타입 (v2.4)

`index.html` — 하나의 SPA(해시 라우터)로 구성된 28페이지 프로토타입. GitHub 업로드 편의상 스크립트를 8개 파일로 분할했습니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 셸 (테마 CSS · 사이드바 · 스크립트 로더) |
| `data1.js` | 공통 데이터 — KQS 권고 8종 · 위원 명단 · MCID/AE 기준 · 조사 표 |
| `data2.js` | KQ1–4 상세 데이터 (PICOTS · EtD · SoF · 합의/공청회) |
| `data3.js` | KQ5–8 상세 데이터 |
| `app1.js`–`app5.js` | 헬퍼 · 페이지 템플릿 · 효과 차트 · 도구 로직 · 라우터 |

### 주요 기능
- **KQ1–8 전 권고 실데이터** — 분석표 PDF(정본) 기준 효과추정치·95% CI·GRADE·EtD 9영역·합의/공청회 투표
- **null·MCID 이중 임계 효과 차트** — 분석표 Figure 재현 (SVG)
- **임상 도구 3종** — 약제 선택 지원 · 치료 반응 평가(MCID 지표별 판정) · 감량·교체 경로
- **KQ4 하위군 분석**(혈중 호산구 층별) · **KQ7 OPTIMAL 감량 단계** 별도 섹션

### 데이터 기준 (2026-08-24 수정본 반영)
- KQ 분석표 KQ1–8 **2026-08-24 수정본** + **진료지침 통합본 2026-08-25** (변경 내역: [`docs/KQ수정본_비교분석_20260826.md`](docs/KQ수정본_비교분석_20260826.md))
- 근거 검색일 2025-12-31 · KQ4 메타분석 재수행+하위군 분석 신설 · KQ8 FEV1(%) 재분석

## 로컬 실행

정적 파일이므로 클론 후 `index.html`을 브라우저로 열면 됩니다 (서버 불필요).

```bash
git clone https://github.com/DrugnSafety/pacen-severe-asthma-guideline.git
open pacen-severe-asthma-guideline/index.html
```

## ⚕️ 의료 면책

본 콘텐츠와 도구는 **연구·교육 목적**이며 개별 환자의 임상 판단을 대신하지 않습니다. 치료 결정은 반드시 담당 의료진과 상의하십시오. 권고안은 학회 인증·최종 승인 전 **초안** 상태일 수 있으며, KQ1–6은 각 약제 대 위약 비교(간접비교)로 약제 간 우열을 시사하지 않습니다.
